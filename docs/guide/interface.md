# 画面構成

Tabstep ウィンドウは、タブバー・ナビゲーションバー（任意）・ホストされたフォルダ表示・ステータスバー（任意）で構成されています。

## 各部の役割

### タブバー
開いているフォルダがそれぞれタブとして並びます。クリックで切り替え、中クリック（設定変更可）や `Ctrl+W` で閉じ、ドラッグで並べ替えられます。右端の `▾` ボタンで全タブの一覧を表示でき、アセットをドラッグ中は右端に `▼ Shelf` ドロップゾーンが現れます。

### ナビゲーションバー
戻る/進む/上ボタンと、現在のパスをクリック可能なパンくずセグメントとして沈んだフィールドに表示するアドレスバーです。収まりきらない親フォルダは `«` の裏に折りたたまれます。[Harmony](/features/harmony) があると、このバー 1 本にホスト先ブラウザ独自のツールバー（作成ボタン＋検索欄）も統合されます。[設定](/guide/settings) で切り替え可能です。

### フォルダ表示
標準の Project ブラウザそのものをホストしています。検索・サムネイル・ドラッグ＆ドロップ・リネーム・コンテキストメニューは標準の Project ウィンドウと完全に同じ動作をします。

### ステータスバー
現在のフォルダのアイテム数と、選択中アセットの数・合計ファイルサイズを下部に表示します。[設定](/guide/settings) で切り替え可能です。

### Tabstep Shelf
メインレイアウトとは別のフローティングウィンドウで、移動途中のアセットやシーンオブジェクトを一時的に置いておけます。詳しくは [Tabstep Shelf](/features/shelf) を参照してください。

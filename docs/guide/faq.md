# よくある質問

## Tabstep は標準の Project ウィンドウを置き換えますか？

いいえ。Tabstep は独自のウィンドウ（**YozoLab → Tabstep**）として開きます。標準の Project ウィンドウはそのまま残り、通常どおり動作します。両方を併用しても問題ありません。

## Harmony は必須ですか？

いいえ、完全に任意です。Harmony がなくても Tabstep は問題なく動作します。ホストしているブラウザは独自のツールバー（作成＋検索）をそのまま維持し、重複するパスヘッダーは削除する代わりにその場で空白化されます。詳しくは [Harmony 連携](/features/harmony) を参照してください。

## タブや履歴、ピンはスクリプトの再コンパイルや Play モードで消えますか？

消えません。タブの状態（タブごとの履歴・検索を含む）は、スクリプトの再コンパイルや Play モード切り替え（ドメインリロード）、さらにはエディタの再起動をまたいでも保持されます。

## Tabstep ウィンドウは複数開けますか？

はい、いくつでも開けます。それぞれが独立したタブ集合を持ちます。タブのコンテキストメニューには *Open in New Window*・*Separate Tab*・*Duplicate Window* もあり、タブをウィンドウ間で移動・複製できます。

## 間違ったタブにドラッグしてしまったら？

タブまたはパスバーのコンテキストメニューにある **Undo Last Asset Move** で、移動したアセットを元に戻せます。詳しくは [アセット操作](/features/asset-management) を参照してください。

## Shelf はアイテムをコピーしますか、それとも移動しますか？

既定では、Shelf からアイテムをドラッグして取り出すと**消費されます**（コピーではなく受け渡し）。ドロップする前にドラッグを戻せば Shelf に復元されます。この挙動は *One-Shot Items* 設定で、[設定](/guide/settings) から OFF にできます。ロックされたアイテムはどちらの設定でも消費されません。

## 噂で聞いたタブ化された Inspector は？

コードベース内にはタブ化された Inspector も存在しますが、統合方法を見直している間、現在は**取り下げられており Unity 上には表示されません** — Inspector を開く経路へのフック処理がエディタを不安定にしていたためです。`TABSTEP_INSPECTOR` スクリプティング定義シンボルの裏に隠されており、その定義がない限りコンパイル・登録・表示のいずれも行われません。

## 対応している Unity のバージョンは？

Unity 2022.3 以降です。

## バグ報告・要望はどこへ？

[GitHub リポジトリ](https://github.com/YozoraKurage/Tabstep) の Issue へお寄せください。

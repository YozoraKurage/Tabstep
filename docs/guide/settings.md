# 設定 (Preferences)

Tabstep の設定は Unity の **Edit → Preferences → Yozolab → Tabstep** から変更できます。設定はエディタ（`EditorPrefs`）に保存され、プロジェクトをまたいでユーザーごとに共有されます。画面下部の **Reset To Defaults** ボタンで、以下すべての値を既定値に戻せます。

## タブ

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| New Tab Folder | `Assets` | 新規タブ（`Ctrl+T` / `+` ボタン）が開くフォルダ。パスが存在しない場合は `Assets` にフォールバックします。 |
| Middle-Click Closes Tab | ON | タブを中クリックすると閉じます。 |
| Open New Tab Beside Active | OFF | 新規タブをバーの末尾ではなく、アクティブなタブの右隣に開きます。 |
| Equal-Width Tabs | ON | ピン留めされていない各タブをブラウザのように均等幅にし、最小幅までバー内で共有させます。OFF の場合は各タブがタイトルに合わせたサイズになります。 |
| Max Tab Title Length | 20 | タブタイトルが省略記号になるまでの長さ（4〜60）。 |

## 表示

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| Navigation Bar | ON | 戻る/進む/上ボタンとクリック可能なパンくずパス。ブラウザ独自の「Assets > ...」パスヘッダーを置き換え、Harmony があるとそのツールバー（作成＋検索）も統合します。OFF にすると標準のブラウザ表示に戻ります。 |
| Status Bar | ON | 現在のフォルダのアイテム数と、選択中アセットの概要（数とファイルサイズ）を表示する下部の行。 |

## 挙動

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| Mouse Side Buttons Navigate | ON | マウスの戻る/進む（サイド）ボタンで、アクティブなタブの履歴を移動します。 |
| Ping Opens New Tab | ON | ウィンドウの外側（Inspector のオブジェクトフィールド、"Show in Project" など）から表示フォルダが変更されたとき、現在のタブを置き換えずに新規タブとして開きます。 |
| WASD Navigation | ON | `W`/`S` で表示中フォルダの選択を上下に移動、`D` で選択したフォルダ/アセットを開き、`A` で戻ります。テキスト入力中（リネーム・検索・パスバー）は無効になります。 |
| Column View Folder Drop | OFF | タイプ別カラム表示で、アセットをフォルダ項目にドロップして移動できるようにします。既定では OFF で、このビュー上のドラッグはシーン・オブジェクトフィールド・フォルダツリーなど本来の対象へ素通りします。 |

## Shelf

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| One-Shot Items | ON | Shelf からアイテムをドラッグして取り出すと消費されます（コピー元ではなく受け渡し用）。OFF にすると手動で削除するまで残ります。ロックされたアイテムはどちらの設定でも消費されません。 |

::: tip Navigation Bar
これを OFF にすると、標準の Project ブラウザ独自のツールバーとパスヘッダーに戻ります。Tabstep のタブ機能自体はそのまま使えますが、アドレスバーやパンくずは表示されません。ナビゲーションバーが置き換える内容は [画面構成](/guide/interface) を参照してください。
:::

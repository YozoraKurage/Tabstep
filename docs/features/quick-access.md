# クイックアクセス

クイックアクセスは、よく戻るフォルダのためのブックマーク一覧に加え、保存済み検索も扱えます。

## ブックマークできるもの

- **フォルダ** — 特定のフォルダへの直接ショートカット。
- **保存済み検索** — 作成したフォルダに紐づいた検索フィルタ。開き直すと、場所とフィルタの両方が同時に再適用されます。

## ブックマークの追加と呼び出し

タブバーの `+` ボタンを右クリックすると、ブックマークしたフォルダと保存済み検索がすべて表示されるクイックアクセスメニューが開きます。新しいブックマークは、このメニューまたはタブのコンテキストメニューから追加できます。

## 保存場所

クイックアクセスの項目は**ユーザーごと・プロジェクトごと**に `UserSettings/` へ保存されます。同じマシンのセッションをまたいで保持されますが、バージョン管理を通じて他の共同作業者と共有されることはありません。

## 関連機能

- [タブごとの検索](/features/search) — 保存済み検索の元になるフィルタ
- [タブ・ピン・ワークスペース](/features/tabs) — ピン留めとの違い: ピンはタブを開いたままにし、クイックアクセスはあとで開くための場所を記憶します

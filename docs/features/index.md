# 機能一覧

Tabstep の主な機能をまとめます。各項目のリンクから詳細ページに移動できます。

## 閲覧

- [タブ・ピン・ワークスペース](/features/tabs) — 複数のフォルダを同時に開き、よく使うタブをピン留め、閉じたタブを復元、タブ構成を丸ごと保存・復元。
- [ナビゲーションと履歴](/features/navigation) — タブごとの戻る/進む、パンくず、候補付きの編集可能なパスバー。
- [タブごとの検索](/features/search) — タブごとに記憶される検索フィルタと、ワンクリックのフィルタチップ。

## 整理

- [Tabstep Shelf](/features/shelf) — 移動途中のアセットやシーンオブジェクトを置いておくフローティングトレイ。
- [クイックアクセス](/features/quick-access) — よく使うフォルダと保存済み検索のブックマーク。

## アセット操作

- [アセット操作](/features/asset-management) — タブ間でのアセット移動、移動の取り消し、フォルダドロップ、パスのコピー＆ペースト。

## 連携

- [Harmony 連携](/features/harmony) — ツールバーを統合する任意の拡張連携。

## 一覧表

| 機能 | 概要 |
| --- | --- |
| タブ | 複数のフォルダを同時に開き、ピン留めとドラッグでの並べ替えに対応 |
| 閉じたタブの復元 | `Ctrl+Shift+T` で最後に閉じた最大 10 個のタブを履歴ごと復元 |
| ワークスペース | タブ構成（順序・ピン・履歴・検索）を名前を付けて丸ごと保存・復元 |
| 複数ウィンドウ | 独立したタブ集合を持つ Tabstep ウィンドウをいくつでも開ける |
| 戻る/進む履歴 | タブごとに保持。マウスのサイドボタンやスプリングロード対応のドラッグ移動も可能 |
| パンくず | クリック可能なパスセグメント。`›` 区切りからサブフォルダを選択可能 |
| パス補完 | パスを入力・貼り付けする際にサブフォルダ候補が表示される |
| タブごとの検索 | タブに戻ると自分の検索フィルタが復元される |
| Tabstep Shelf | アセット/オブジェクトを一時的に置き、Unity のドラッグ＆ドロップが届く場所ならどこへでも取り出せる |
| クイックアクセス | よく使うフォルダと保存済み検索。ユーザーごと・プロジェクトごとに保存 |
| タブ間移動 | アセットをタブヘッダーへドラッグして、そのフォルダへ移動 |
| 移動の取り消し | 直前に移動したアセットを元に戻す |
| Harmony 連携 | ホスト先ブラウザのツールバーとパスヘッダーを 1 本のバーへ統合 |

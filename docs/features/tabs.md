# タブ・ピン・ワークスペース

Tabstep で開いたフォルダは、Web ブラウザのようにそれぞれタブになります。

## 開く・閉じる

- `Ctrl+T`（または `+` ボタン）で、[設定](/guide/settings) に指定したフォルダに新規タブを開きます。
- `Ctrl+W` でアクティブなタブを閉じます。最後のタブを閉じるとウィンドウも閉じます。ピン留めされたタブは対象外です。
- タブを中クリックすると閉じます（設定で変更可能）。
- タブバーの `▾` ドロップダウンで、開いている全タブの一覧を表示できます。画面に収まらない数のタブがあるときに便利です。

## タブの並べ替えと識別

タブ見出しをドラッグして並べ替えられます。異なる親フォルダにある同名フォルダのタブは、親フォルダ名も併記されます（例: `Scripts — Player` と `Scripts — Enemy`）。どちらのタブか迷うことがありません。

## ピン留め

タブを右クリックして **Pin** を選ぶと、次のようになります。

- バーの左端に移動する
- フォルダアイコンのみに縮小される
- `Ctrl+W` や中クリックの影響を受けなくなる（コンテキストメニューから明示的に閉じることは可能）

*Close Others* と *Close to the Right* は、どちらもピン留めされたタブを対象外にします。

## 閉じたタブの復元

`Ctrl+Shift+T`（またはタブバーのコンテキストメニュー）で、最後に閉じたタブを履歴ごと復元できます。最後に閉じた 10 個のタブまで記憶されるため、連続して閉じてしまっても遡れます。

## ワークスペース

タブ構成全体 — 順序・ピン・タブごとの履歴・タブごとの検索 — を、`▾` ドロップダウンから名前を付けて保存し、あとで一度に復元できます。プロジェクト内の異なる作業領域（例: 「UI 作業」と「レベル 3 のアセット」）を、どちらの場所も失わずに切り替えたいときに便利です。

## 複数ウィンドウ

Tabstep ウィンドウはいくつでも同時に開けます。それぞれが独立したタブ集合を持ちます。タブのコンテキストメニューには次の項目があります。

- **Open in New Window** — タブのコピー（履歴込み）を新しいウィンドウで開きます。
- **Separate Tab** — タブを現在のウィンドウから切り離し、隣にドッキングします（ドッキングできない場合は右側にフロート表示されます）。
- **Duplicate Window** — ウィンドウ全体（すべてのタブ、ピン、アクティブなタブ）を複製します。
